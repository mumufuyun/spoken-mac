## 配置迁移

模式配置由版本7升级至8。仅当内置场景规则与2.4.8旧默认值逐字一致时更新，用户修改过的场景、基础规则、自定义模式、名称和当前选择保持不变。写入失败保留原文件，重试仍按同一规则迁移；再次加载不会重复修改。

内容分享的冻结文本独立成文，AI 指令的任务说明位于公共规则前。默认请求保留这两种排列方式；用户修改基础规则或场景内容后，继续使用可编辑的正常组合逻辑。设置保存仅裁剪首尾空白时，仍还原默认请求的精确文本，避免无意改变已测版本。

正式版已有的个人背景相关性、偏好优先级及禁止机械同音替换规则继续保留；模型连接、思考偏好、输出语言及请求参数未修改。带个人背景时，使用当前正式版背景模板包裹冻结任务，而非退回评测时的旧背景模板。
