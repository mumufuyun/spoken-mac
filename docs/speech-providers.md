# 语音供应商接入

Spoken 2.3.0 新增多供应商语音连接。语音识别负责把声音转成文字，与后续 AI 整理使用的模型分别配置。

## 添加与切换

1. 打开“设置 → 语音识别”，点击“添加连接”。
2. 选择供应商，填写名称及该语音服务的凭据。预设已填好地址和模型或资源 ID，需要时展开高级设置修改。
3. 选择“云端识别”或“自动选择”，点击“保存并使用”。同一家供应商可以保存多组连接。
4. 日常从菜单栏“语音识别”直接选择已保存的连接，也可切回本地识别。录音和处理期间不能修改或切换语音连接。

保存前的编辑只在草稿中；离开页面或选择另一连接时，会提示保存、放弃或取消。保存失败会保留原配置。删除当前连接会切回本地识别，不自动使用其他云端密钥。

## 预置供应商

| 供应商 | 使用的服务 | 需要填写 | 默认模型或资源 ID |
| --- | --- | --- | --- |
| 千问 | 百炼 Realtime ASR | API Key | `qwen3-asr-flash-realtime` |
| 讯飞 | 实时语音转写大模型 | App ID、API Key、API Secret | 默认语种 `autodialect` |
| 豆包（火山引擎） | 流式语音识别 V3 | 火山语音新版控制台 API Key | `volc.seedasr.sauc.duration` |

- **千问**：填写语音识别可用的百炼密钥。已有模型名称及业务空间专属域名会迁移保留；新建连接使用公共域名。参见[百炼实时语音识别](https://help.aliyun.com/zh/model-studio/qwen-real-time-speech-recognition)。
- **讯飞**：需开通“实时语音转写大模型”，普通听写服务的凭据不通用。默认语种覆盖中英与方言；`autominor` 需另行开通。参见[讯飞接入说明](https://www.xfyun.cn/doc/spark/asr_llm/rtasr_llm.html)。
- **豆包**：填写火山语音新版控制台的 API Key，不是火山方舟聊天模型密钥。资源 ID 应对应已开通的小时版或并发版；本版不提供旧 App Key + Access Token 鉴权。参见[火山引擎流式识别说明](https://www.volcengine.com/docs/6561/1354869)。

额度、地域和开通范围以供应商控制台为准。保存成功只代表本地配置已保存，不代表已验证远端凭据。

## 自定义接口

自定义连接必须选择实际兼容的协议，不能只填任意 ASR 或聊天模型 URL。

| 协议 | 传输方式 | 结果返回 |
| --- | --- | --- |
| 千问 Realtime 兼容 | WSS，百炼会话及音频事件 | 录音期间持续更新 |
| 讯飞实时转写大模型兼容 | WSS，讯飞签名及二进制 PCM | 录音期间持续更新 |
| 豆包流式 V3 兼容 | WSS，火山语音鉴权及二进制协议 | 录音期间持续更新 |
| OpenAI 音频转写兼容 | HTTPS，Bearer 密钥、multipart WAV 和模型名 | 停止录音后返回 |

HTTP 方式填写完整转写地址，例如 `https://example.com/v1/audio/transcriptions`，不是 `/chat/completions` 地址。接口需接受 `file`、`model`、`response_format=json`，并返回 JSON 的 `text` 字段。可选填识别语种。协议参考 [Audio Transcriptions](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)。

音频以 16 kHz、单声道、16-bit PCM 采集。HTTP 路径只在停止后提交内存中的 WAV，原始 PCM 上限 24 MB，请求总等待上限 60 秒。流式路径按供应商要求分帧发送，待发送缓存最多约 30 秒；超限报错，不静默丢弃音频。仅支持 HTTPS/WSS，密钥填写在专用字段，不能放进 URL。

## 配置与失败处理

- 连接配置保存于 `speech-connections-v1.json`；各连接凭据分别存入本机 Keychain，不写入 JSON，也不借用其他语音或 AI 模型连接的密钥。
- 首次升级会迁移旧千问配置及语音密钥，完整保存成功后才启用。旧值保留；失败时不覆盖，不重复迁移。配置损坏或钥匙串读取失败会提示错误并阻止覆盖。启动时不请求交互授权；若旧密钥需要授权，解锁 Mac 后进入语音识别设置，点击“重试读取旧配置与密钥”，按系统提示允许访问。编辑页面也提供连接密钥重读入口。
- 每次开始录音时固定供应商、协议、地址、模型和凭据。取消后丢弃迟到结果；停止后出错仍会完成收尾，避免一直等待。
- 收尾失败时保留已经识别的文字，单独提示可能遗漏，不再交给 AI 处理；没有文字则显示失败提示，不输出空结果。
- “自动选择”在云端录音失败时尝试本地识别，故障前的云端音频不会重放到本地。不会自动转发给另一个云端供应商。已停止录音时不重新录音。
- 千问保留原有预连接和重连策略。讯飞、豆包不建立空闲预连接，也不自动重发失败录音；HTTP 不自动重传。减少空闲会话和重复提交。

## 验证范围

离线回归使用临时配置、模拟 Keychain、WebSocket 和 HTTP，不读取用户密钥或语音。覆盖迁移、保存失败回滚、密钥隔离、协议签名及帧解析、分段修正、结束收尾、超时、取消和迟到响应、界面草稿与忙碌限制。

本地构建及原生界面检查与真实供应商验收分别记录。新接入的讯飞、豆包和自定义接口尚需使用有效凭据验证鉴权、真实录音、长语音与最终粘贴；离线通过不代表供应商实测通过。本轮没有进行付费接口调用。
