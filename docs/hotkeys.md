# 自定义快捷键与冲突处理

默认 `⌥ 空格`。菜单栏点击当前组合，或进入“设置 → 快捷键与操作”，即可录入新组合、保存、恢复默认或重新检测。

## 使用与录入

回到目标输入框，按一次开始录音，再按一次结束；处理中再次按当前快捷键或 Esc 取消。录音时也可按 Esc 取消。打开着模式面板时，首次按快捷键先关闭面板，回到输入框后再次按下开始。

组合至少包含 Command、Control、Option 之一，可叠加 Shift。支持字符键、空格和 F1–F20。纯修饰键、裸键、仅 Shift、单独 Fn 和 Esc 不可保存。Spoken 的保存、窗口及常用编辑命令也不可占用。

录入期间只暂停 Spoken 自己的快捷键，不停用系统或其他软件的快捷键。按键松开后才接受草稿并恢复原组合；Esc 取消，失焦、离开页面和关闭窗口也会恢复。恢复失败会显示不可用。保存前，菜单栏、录音浮窗和“当前快捷键”一直显示已保存的组合。

录音、处理及录音面板关闭前均禁止修改；当前快捷键仍可用于结束或取消。未保存草稿离开页面时可保存、放弃或取消离开。首次打开模式面板显示操作引导，只有点击“知道了”后才不再自动出现；设置页始终保留说明。冲突警示优先于引导。

## 冲突与恢复

| 情况 | 结果 |
| --- | --- |
| 首次启动默认组合被占用 | 显示一次不抢焦点的提示，菜单栏持续警示，不自动选其他组合 |
| 已保存组合在再次启动时被占用 | 保留保存值，显示不可用，不恢复默认 |
| 新组合或恢复默认时遇到占用 | 不切换、不保存；草稿保留，原有效快捷键继续工作 |
| 持久化失败 | 清理临时注册，原配置和原有效注册保留 |
| 唤醒、录入结束后恢复注册失败 | 显示不可用，允许修改或重新检测 |
| 关闭占用软件后重新检测 | 尝试注册已保存组合，成功后清除警示；不保存草稿 |

校验依次检查有效组合、Spoken 自身命令、系统已启用的 symbolic hotkeys，以及 Carbon 独占注册结果。无法确定占用者时只提示“系统或其他应用占用”，不推测软件名称。

macOS 没有所有应用快捷键的完整清单。“已注册”仅表示系统接受了注册：

- 其他应用的非独占注册、应用内快捷键和自行监听按键可能无法检测。
- 在本次实测的 macOS 26.6.2 / 25G83 上，已有独占注册返回 `eventHotKeyExistsErr (-9878)`；已有非独占注册仍返回成功。
- Carbon 独占注册可能暂时阻止其他非独占注册接收同一组合。这是系统 API 的限制，不能承诺所有占用都能预先发现。出现此类冲突时请换键。
- 不修改其他软件设置，不对已检测到的冲突强制注册。

依据为当前 SDK `HIToolbox/CarbonEvents.h` 中 `CopySymbolicHotKeys`、`RegisterEventHotKey` 和 `kEventHotKeyExclusive` 的定义，以及仓库隔离进程测试的实际结果。

## 实现与配置

`HotKeyConfiguration` 保存物理键码、Carbon 修饰键位掩码和版本号。存储文件为 `~/Library/Application Support/Spoken/Configuration/hotkey-v1.json`，使用现有 `ConfigurationFile` 原子替换与 0600 权限。没有文件时使用默认值；损坏或不支持的配置不会被启动过程覆盖，需成功保存后修复。

`HotKeyService` 区分保存值和未注册、已注册、录入暂停、不可用四种状态。服务、注册器和存储可注入。所有操作在主线程串行完成，新组合注册、持久化成功后才切换活动 ID 并释放旧注册；相同组合保存不重复注册。暂存或过期注册的事件不会触发录音。

按下和释放事件共同维护长按去重；恢复注册时已按住的键需先释放。唤醒观察者和 Carbon 事件监听器只安装一份。键盘布局切换会刷新显示名称，不改变物理键码。各处提供中文修饰键和注册状态标签。

`HotKeyCaptureSession` 管理录入与取消；原生录入控件仅在录入期间安装当前窗口的本地事件监听，离开后移除。它不建立额外的全局键盘输入监听。日志仅记录快捷键注册的键码、修饰键、阶段和错误码，不记录其他键盘输入。

## 验证

```bash
# 实际源码 + 假注册器、内存偏好、临时配置；不请求模型
bash scripts/run_offline_ai_tests.sh

# 原生注册器 + 独立持有进程，覆盖独占/非独占与释放后重试
bash scripts/run_hotkey_integration_tests.sh

# 深浅色、完整模式、冲突和最小设置窗口
bash scripts/run_offline_ai_tests.sh --render-ui build/hotkey-ui

# 隔离设置页：真实 Carbon 注册、模拟录音、临时配置
bash scripts/build_hotkey_smoke.sh

# 本机构建，不安装、不启动
bash scripts/build_local_app.sh
```

隔离快捷键程序初始使用 `⌃⌥⌘ K`，处理阶段仅为模拟，不使用麦克风和模型。界面中的“模拟 Carbon 按下 / 松开”投递合成 Carbon 事件，可检查处理链路；这不等价于实体键盘验收。实体键盘需另外核对开始、结束、取消、长按及跨应用焦点。
