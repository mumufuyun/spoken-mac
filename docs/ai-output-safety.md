# AI 正文输出保障

目标：尽量防止模型内部思考、分析草稿和接口元数据进入最终粘贴文本；无法可靠确定正文时，保留原转录并提示。此方案不承诺对所有无标签文本实现完全识别。

## 本次诊断

本机日志显示，新版应用的 AI 指令请求使用 qwen3.8-flash，思考开关为关闭，返回结果被旧校验判为成功。日志没有保留模型正文，无法还原用户报告的那一次输出，也无法确认其具体格式。

代码中可确认的缺口：旧过滤器只处理完整 `<think>...</think>`，对其他标签、正文后未闭合的标签、无标签的模型自述分析覆盖不足；自定义模式只处理开头的思考块；最终粘贴前只检查空文本。新增回归使用合成响应复现这些缺口。

## 已实现的保护

| 层级 | 行为 |
| --- | --- |
| 请求参数 | 沿用各连接的思考偏好；支持关闭的模型默认关闭。MiniMax 继续请求 `reasoning_split=true`。关闭思考只减少发生机会，不代替输出检查。 |
| 运行时提示词 | 每次请求加入只返回正文的系统约束，明确排除模型自己的推理、草稿、自检、通道标签和接口元数据。已有保存的 Prompt 也生效，无需重置用户规则。任务本身要求的分析结论、操作步骤和代码仍可输出。 |
| 响应解析 | 只接收已知最终文本字段。忽略独立的 reasoning/thinking 内容；对混合内容块只接收明确的 text/output_text。未知结构、非最终通道、工具调用不作为正文。已有响应结构无效时不尝试从其他字段拼出结果。 |
| 重复推理检查 | 如果独立推理字段中至少 16 字的完整片段又出现在正文中，拦截整份结果。该检查不尝试语义匹配，也不拦截常见短词的偶然重合。 |
| 内容检查 | 清除正文中已知、成对且边界完整的思考标签，支持大小写、属性、多个块及嵌套。未闭合、孤立闭合、错配、残留协议标签、明显序列化响应和明确的内部推理标题触发回退。 |
| AI 指令专项 | 额外检查新增的“分析/思考”标题和“我需要先分析用户……”等模型自述。原转录已包含的相同表达不直接视为模型泄露。 |
| 最终交付 | 粘贴前按停止录音时冻结的模式再次检查，即使前面的服务误报成功，也必须经过检查。取消后仍不交付迟到结果。 |

正常代码块和行内代码中的标签字面量保持原样；显式标为 thinking/reasoning 等内部过程的代码块不享受这个例外。自定义模式继续保留 Markdown、代码和 Unicode，也不会因为任务本身含“分析”一词就删除正文。无法可靠区分时不猜测截取位置，而是回退原转录。

## 回退与诊断

- 明确能分离的思考标签：移除后再次检查正文，正文为空仍算失败。
- 存在疑似内部内容或边界不完整：不粘贴模型结果，返回原转录，浮窗提示“AI 输出含疑似思考过程，已保留原文”。
- 可疑输出不自动重试，不新增模型调用费用；原有网络重试仍共用截止和冻结的请求。
- `AIProcessing` 日志新增 `outcome=unsafe_output`。发生正文清理或丢弃独立推理字段时记录 `output_guard=cleaned`、`separated_reasoning` 和正文字数；不记录正文、推理、Prompt、密钥或完整响应。
- `cleaned` 也可能表示普通包装语或兼容性字符清理，不能直接用其次数计算推理泄露率。复现时记录大致时间、模式、模型及异常格式即可定位相应请求；需要原始样例时由用户明确提供并脱敏，不开启常态全文日志。

## 回归与后续维护

离线测试使用模拟 HTTP、模拟钥匙串和临时配置，覆盖正文/推理分离、混合内容块、兼容解析路径、重复推理、嵌套和残缺标签、无标签自述、协议元数据、任务正文误拦截、粘贴前复查、取消、旧 Prompt 生效、日志隐私和长输出。

每次修改 Prompt、响应解析或供应商适配，都运行 `bash scripts/run_offline_ai_tests.sh` 和本地构建。发现新格式后先加入合成回归，再调整规则；不通过扩大“分析、思考”等普通词的删除范围来修复个案。

这些检查在本地执行，不增加额外模型往返。规则无法可靠识别所有自然语言、变体标签或被伪装为代码的内部过程；过于接近内部过程的合法正文也可能被保守回退。没有本次原始响应，因此本轮验证证明的是已覆盖格式的防护，不能量化真实环境的复发概率。

## 官方格式依据

- [阿里云百炼深度思考](https://help.aliyun.com/zh/model-studio/deep-thinking)：`enable_thinking` 控制混合思考模型；思考通过 `reasoning_content` 返回，正文通过 `content` 返回。
- [MiniMax OpenAI 兼容接口](https://platform.minimaxi.com/docs/api-reference/text-openai-api)：`reasoning_split` 控制思考内容的分离方式；M2 系列不能关闭思考，因此仍须检查最终输出。
