被 macOS 拦住了？

如果提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”，先关闭提示，再打开下面的设置页。

打开“隐私与安全性” ↗

请在 Mac 上点击。浏览器可能先询问是否打开“系统设置”；跳转后可能需要向下滚动到“安全性”。

  1. 找到关于 Spoken 的拦截记录，点击“仍要打开”（部分系统先显示“打开”）。
  2. 按系统提示验证身份，再确认打开。
  3. 在屏幕右上方菜单栏找到 Spoken 麦克风图标，继续完成权限设置。

没有跳转？手动进入苹果菜单 → 系统设置 → 隐私与安全性 → 安全性。
没有拦截记录？先把 Spoken 拖入“应用程序”，双击尝试打开，再返回此页；“仍要打开”通常在尝试后约一小时内可用。

下载来源与后续授权

当前测试版采用本地签名，尚未完成 Apple Developer ID 签名与公证。请确认安装包来自可信下载页面或项目维护者，再决定是否继续打开。

若提示“将损坏你的电脑”“包含恶意软件”或“应用已损坏”，请停止使用当前包，重新从可信来源下载或反馈开发者。受公司或学校管理的 Mac 可能需要管理员协助。

本页只提供设置入口，不能检测拦截或代替系统确认。允许启动后，自动填入输入框还需单独授予“辅助功能”权限；按 Spoken 内的引导完成即可。
