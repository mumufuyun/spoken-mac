# 找回上次输入

本轮基于 2.4.2 开发，本机试用版为 2.4.3（243.1），需求见 [PRD](../PRD.md#找回上次输入本轮开发)。菜单结构不变，录音浮窗保持 420 × 224，找回页为 420 × 420。

## 数据与流程

1. SpeechService 完成 ASR 收尾，先通过 onRawFinal 交付原文及完整性标记，再通过原有 onFinal 交付本地格式化后的正常输入。
2. RecordingViewModel 拒绝已取消或已提交会话的原文。InputRecoveryStore 忽略空文本，只在内存保留一份最近原文。
3. 浮窗入口在未口述且有原文时可用；音频活动与 ASR 非空 partial 都能禁用入口，覆盖 HTTP 收尾才出字的服务。
4. 点击入口先取消当前录音并隐藏录音面板，再显示可成为键盘焦点的非激活面板。支持选择文字、复制及场景选择。
5. 重整通过独立 AIProcessingService 发起，请求标识和原文标识共同拒绝迟到回调；校验成功后通过本次找回页面绑定的回调交付，关闭浮窗并复用正常文本注入链路。

录音音频的检测复用现有 PCM 阈值，并支持原生 Float32 / Int16 缓冲区。它只限制入口，不修改送入识别器的音频；低声和环境噪声下的体验仍需设备验收。

## 场景与请求

- 首次打开当前原文时继承 ModeStore 的当前场景；本页切换只更新内存中的 selectedModeID。
- 点击「整理并输入」时，AIProcessingSnapshot 按本页 ID 读取当前规则，并冻结模型、密钥、输出语言及个人背景。不写 ModeStore，不改变下一次录音。
- 场景列表包含内置和自定义模式。所选自定义模式被删除后，明确要求重选。
- 切换场景保留旧结果，并标记其实际场景。配置校验失败也保留旧结果；有效新请求开始才清除。
- 原文 / 结果共用一个正文区。复制按钮只复制当前页内容，不注入。成功结果保留在内存；重新打开、切换场景或切换正文不会再次输入。取消、失败和关闭都不会删除原文。
- 全局活动从 recovering 直接交接至 injecting，输入结束前阻止更新安装。正常录音开始会同步取消尚未交付的重整，旧回调不能写入或把新录音状态改回空闲；短暂输入阶段不响应新录音快捷键。
- 唤起录音时捕获目标应用和输入控件的标识，不读取控件正文。交付时恢复目标应用，粘贴前再次恢复并核对输入焦点。控件失效或不支持识别时只保留剪贴板结果并提示手动粘贴；不猜测另一个输入位置。
- 复制、权限及事件失败复用现有交付提示。输入失败时保留已整理的结果；剪贴板失败提供重试复制。

## 验证

找回功能的离线检查覆盖原文保真、空输入、覆盖规则、场景隔离与快照、原文 / 结果复制、异常输出、取消和迟到回调、删除自定义场景、更新互斥、音频活动检测及浮窗入口条件，并验证只交付一次、交付目标冻结、输入阶段更新互斥和目标失效时不发送粘贴事件。

原生界面检查覆盖浅深色、单行录音底栏、原文、整理中、换场景后的旧结果及长文失败状态。可通过现有离线检查的 `--render-ui` 生成检查图；`--build-ui-smoke` 的「找回输入演示」可操作真实组件，数据与模型均为模拟。

已按用户要求打包 DMG 并安装到本机，未发布到下载站或更新源。真实麦克风、实际供应商网络、跨应用输入焦点以及用户常用快捷键仍需试用验收。
