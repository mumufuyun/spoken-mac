# 2.4.2 场景提示词更新

本版合入 2026-10-02 评测后用户确认的 candidate-13，覆盖流畅转写、日常聊天、工作沟通、正式材料、会议记录、内容分享和 AI 指令。客户端更新组件沿用 2.4.1。

## 迁移

配置版本从 6 升至 7。基础规则和各内置场景分别与冻结的旧默认值精确匹配，只有未编辑项更新。手动编辑的规则、自定义模式、名称和当前选择保留；写入失败保留原配置并允许重试。

## 来源与验证边界

评测使用固定 194 题、qwen3.8-flash、关闭思考，按忠实性、整理效果和表达风格全部通过计算严格通过。第 13 版为 184/194（94.85%），原基线为 158/194（81.44%）；未达到 95% 门槛。题集已经参与调优，评分为非盲 AI 评审，不能当作未见任务的准确率、独立人工验收或完整应用通过率。长文本、正式材料和会议记录仍有未解决问题。

本次发布不重新运行有费用的模型评测。将冻结的基线与第 13 版提示词快照纳入 `SpokenTests/Offline/Fixtures/prompt-v7/`，离线测试逐场景对比实际 Swift 组合结果，验证发布版本与评测版本一致，并覆盖规则迁移、保留用户修改及失败重试。来源摘要及文件哈希见同目录 `provenance.json`；不发布本地逐题口述和模型输出。

客户端更新文案见 `docs/releases/2.4.2.json`。网站只同步版本和下载包，不增加软件更新功能展示。
