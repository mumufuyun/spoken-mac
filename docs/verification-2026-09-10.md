## 本轮修正

- 删除自定义模式时，保留尚未保存的全局基础规则，避免连带丢失其他模式的规则修改。
- 模型密钥读取失败后重试，不再把未保存的连接名称和模型参数误标为已保存。
- 语音识别设置区分“没有密钥”和“钥匙串读取失败”；读取失败时禁止保存，避免覆盖旧密钥。
- 麦克风准备期间停止录音也会结束当前会话并取消启动重试；自动停止采集时立即冻结处理配置。
- 浮窗被取消后，不再执行队列中尚未开始的录音启动；启动失败会关闭录音流程。
- 修正本机 IPv6 URL 校验与完整接口路径识别；连接测试统一去除模型和地址两端空白。
- 安装前发现视图默认属性会提前初始化正式配置单例，即使传入测试配置也会产生空的正式配置文件。改为显式初始化属性包装器，并给离线测试增加正式文件访问拦截和视图注入回归。

| 草稿保护 | 页面切换提示；取消后保留草稿；模拟磁盘写入失败后阻止跳转，恢复后可保存 |

## 验证边界

本机仅有 Command Line Tools，无法导入 XCTest；本轮实际执行的是编译真实应用源码的 Swift 离线测试器，不是 Xcode 的 XCTest target。没有调用外部模型，没有使用私有语音。真实麦克风、跨应用粘贴、前台焦点保持和完整 VoiceOver 操作仍需实际验收。

## 复现

```bash
bash scripts/run_offline_ai_tests.sh --render-ui build/review-ui
bash scripts/build_local_app.sh
bash scripts/run_offline_ai_tests.sh --build-ui-smoke
```

最后一条仅构建隔离的界面测试应用，不启动它。应用中的“完成合成语音”会在八秒后触发模拟 ASR 回调，可用于检查停止后的锁定和取消。
