# 浮窗状态展示优化 v4

## 需求确认

### 阶段展示（三个状态）
1. **录音**：显示"录音中"（红色）
2. **模式**：显示当前模式名称，如"润色" / "翻译" / "摘要"等（黄色，表示处理中）
3. **输入**：显示"输入中"（黄色，表示文本注入中）

### 状态流转
```
录音(红) → 模式名(黄) → 输入(黄) → 浮窗消失
```

### 规则
- 模式名称不加"中..."后缀，直接显示模式名（如"润色"、"翻译"）
- 不区分"处理完成"和"文本注入"，统一为"输入"阶段
- 颜色：红=录音 / 黄=处理和输入 / 绿=完成（可选）

## 修复方案

### 1. RecordingViewModel 改造

新增 `@Published var displayStatus = ""`：

```swift
class RecordingViewModel: ObservableObject {
    @Published var isRecording = false
    @Published var isProcessing = false
    @Published var partialText = ""
    @Published var statusText = ""        // 底部识别文本
    @Published var displayStatus = ""      // 右上角状态
    @Published var isCancelled = false
    
    func startRecording() {
        // ...
        displayStatus = "录音"
        
        SpeechService.shared.startRecording(
            onPartial: { [weak self] text in
                self?.partialText = text
                self?.lastRecognizedText = text
                self?.statusText = text           // 底部展示识别文本
                self?.displayStatus = "录音"       // 右上角保持状态
            },
            onFinal: { [weak self] text in
                self?.isRecording = false
                self?.isProcessing = true
                self?.partialText = ""
                self?.statusText = ""              // 清空底部文本
                // 根据当前模式设置状态
                let modeRaw = UserDefaults.standard.string(forKey: "spokenMode") ?? "直接输入"
                let mode = SpokenMode(rawValue: modeRaw) ?? .direct
                if mode == .direct {
                    self?.displayStatus = "输入"
                } else {
                    self?.displayStatus = mode.rawValue  // 直接显示模式名：润色/翻译/摘要...
                }
                // ...
            }
        )
    }
    
    private func processAndInput(_ text: String) {
        // ...
        if mode == .direct {
            displayStatus = "输入"
            isProcessing = false
            onComplete?(text, frontmostApp)
            return
        }
        
        // AI 处理中状态已在 onFinal 中设置（如"润色"）
        
        MiniMaxService.shared.process(...) { result in
            // ...
            // 处理完成，进入输入阶段
            strongSelf.displayStatus = "输入"
            strongSelf.isProcessing = false
            
            // 延迟后执行文本注入
            DispatchQueue.main.asyncAfter(deadline: .now() + 0.5) {
                strongSelf.onComplete?(finalText, strongSelf.frontmostApp)
            }
        }
    }
}
```

### 2. AppDelegate onComplete 改造

```swift
viewModel.onComplete = { [weak self] text, appFromViewModel in
    guard let strongSelf = self else { return }
    
    // 直接执行注入，displayStatus 已经是"输入"
    // ... 执行注入逻辑
    
    // 注入完成后关闭浮窗
    strongSelf.recordingPanel?.orderOut(nil)
    strongSelf.recordingPanel = nil
}
```

### 3. UI 改造

**右上角状态区**（使用 displayStatus）：

```swift
if viewModel.isRecording {
    HStack(spacing: 5) {
        Circle().fill(Color(hex: "#c0392b")).frame(width: 6, height: 6)
            .scaleEffect(pulseScale)
            .animation(...)
        Text(viewModel.displayStatus)  // "录音"
            .font(.system(size: 11, weight: .medium))
            .foregroundColor(Color(hex: "#c0392b"))
    }
} else if viewModel.isProcessing || viewModel.displayStatus == "输入" {
    HStack(spacing: 5) {
        Circle().fill(Color(hex: "#f39c12")).frame(width: 6, height: 6)
            .scaleEffect(pulseScale)
            .animation(...)
        Text(viewModel.displayStatus)  // "润色" / "翻译" / "输入"
            .font(.system(size: 11, weight: .medium))
            .foregroundColor(Color(hex: "#f39c12"))
    }
}
```

**底部区域**：
- 录音中：显示实时识别文本 `statusText`
- 其他阶段：空
